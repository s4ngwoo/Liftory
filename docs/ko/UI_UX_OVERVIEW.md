# Liftory UI/UX 화면 갤러리 및 디자인 평가 가이드

본 문서는 **Liftory (Android 네이티브 오프라인 우선 운동 트래킹 앱)**의 화면별 실제 구동 스크린샷과 UI/UX 디자인 철학, 인터랙션 설계, 사용성 평가 포인트를 체계적으로 정리한 문서입니다.

---

## 1. UI/UX 디자인 원칙 및 철학 (Core Design Philosophy)

1. **엄지 손가락 친화형 인체공학 (Thumb-Zone & Bottom-to-Top Layout)**:
   - 스마트폰을 한 손으로 쥐고 운동 기구 사이에 서서 빠르게 기록하는 헬스장 환경을 고려하여, 주요 입력 필드와 액션 버튼을 화면 하단에 집중 배치하였습니다.
   - 키보드가 올라와도 상단 데이터가 가려지지 않도록 컴팩트한 3열 가로 그리드 및 자동 스크롤(`verticalScroll`)을 적용하였습니다.

2. **인지 부하 최소화 (Zero Cognitive Load)**:
   - 복잡한 메뉴 트리를 지양하고, **Sessions(기록), Routines(루틴), Exercises(종목), Stats(통계)**의 직관적인 4개 탭 네비게이션으로 단일화하였습니다.
   - 웨이트 트레이닝과 유산소 운동(Cardio) 선택 시 입력 라벨과 퀵 버튼(`무게/횟수/+2.5kg` ↔ `속도/시간/+5분`)이 스마트하게 자동 전환되어 사용자가 별도의 모드 설정을 고민할 필요가 없습니다.

3. **실시간 시각 피드백 (Real-time Visual Feedback)**:
   - 무게와 횟수를 입력하는 즉시 Epley 공식 기반의 추정 1RM(`🔥 예상 1RM 106.7 kg`)이 동적으로 계산되어 즉각적인 성취감을 제공합니다.
   - 세트 저장 즉시 자동 작동하는 휴식 타이머, 상단 인앱 배너, 시스템 상단바 크로노미터 알림을 통해 다른 화면이나 앱으로 이동해도 끊김 없는 운동 흐름을 유지합니다.

4. **현실적인 제약 반영 (Single Active Session Enforcement)**:
   - 동시에 두 개 이상의 운동을 진행할 수 없는 현실을 반영하여, 중복 세션 생성을 방지하고 친절한 충돌 해결 대화상자(이어하기 vs 종료 후 새로 시작 vs 취소)를 제공합니다.

## 2. 화면별 스크린샷 및 UI/UX 상세 분석

### [Screen 01] 운동 세션 상세 화면 (초기 상태)
- **파일명**: `01_session_detail_empty.png`
- **화면 분류**: 세션 상세 (Workout Session Detail - Initial State)

![운동 세션 초기 화면](../screenshots/01_session_detail_empty.png)

#### 주요 UI 구성 요소
- **상단 헤더**: 뒤로가기 버튼, 세션 제목, `총 0세트 완료` 상태 표시, 우측 상단 `[✓ 완료]` 버튼.
- **총 운동 시간 대시보드 카드**: 시각적인 스톱워치 아이콘, 실시간 초 단위 카운트다운(`01:34`), 보라색 액센트의 `[✓ 운동 완료]` 버튼.
- **휴식 타이머 프리셋 칩**: `60초`, `90초`, `120초`, `스톱워치` 등 1터치로 시작 가능한 빠른 선택 칩.
- **운동 세션 정보 카드**: 세션명 인라인 수정(연필 아이콘), 삭제(휴지통 아이콘), `[+ 운동 종목 추가]` 주 버튼.
- **빈 상태(Empty State) 안내**: 친절한 플레이스홀더 텍스트와 큰 `+ 운동 추가하기` 버튼으로 첫 행동을 자연스럽게 유도.

#### UX 평가 포인트
- 운동 시작 직후 사용자가 다음에 무엇을 해야 할지 직관적으로 인지할 수 있는지.
- 타이머 영역과 세션 정보 영역의 시각적 계층 구조가 명확한지.

### [Screen 02] 운동 종목 선택 다이얼로그 (유산소 필터)
- **파일명**: `02_exercise_picker_cardio.png`
- **화면 분류**: 모달 바텀시트 / 운동 선택 (Exercise Picker Modal)

![운동 종목 선택 유산소 필터](../screenshots/02_exercise_picker_cardio.png)

#### 주요 UI 구성 요소
- **상단 드래그 핸들 & 타이틀**: `운동 라이브러리 (Exercises)` 시각적 바텀시트.
- **실시간 검색 바**: 종목 이름 또는 머신 브랜드를 검색할 수 있는 텍스트 필드.
- **기구 구분 탭 칩**: `전체 기구`, `🏋️ 프리웨이트`, `⚙️ 머신운동`, `🏃 유산소`.
- **부위 탭 칩**: `전체 부위`, `가슴`, `등`, `하체`, `어깨`, `팔`.
- **종목 카드 리스트**:
  - `Elliptical (일립티컬)` - Cardio · 유산소 (Life Fitness)
  - `Incline Treadmill (마이마운틴 / 인클라인 러닝)` - Cardio · 유산소 (MyMountain)
  - `Rowing Machine (로잉머신)` - Cardio · 유산소 (Concept2)
  - `StairMaster (천국의 계단 / 스텝밀)` - Cardio · 유산소 (Matrix)
  - `Stationary Cycle (실내 사이클)` - Cardio · 유산소 (Concept2)

#### UX 평가 포인트
- 상단 칩 터치 시 딜레이 없는 즉각적인 필터링 반응 속도.
- 브랜드 정보가 서브 텍스트로 은은하게 노출되어 특정 머신을 찾는 사용자에게 주는 편의성.

### [Screen 03] 웨이트 세트 입력 바텀시트
- **파일명**: `03_set_editor_weight.png`
- **화면 분류**: 입력 바텀시트 (Weight Set Editor Sheet)

![웨이트 세트 입력 바텀시트](../screenshots/03_set_editor_weight.png)

#### 주요 UI 구성 요소
- **헤더**: 덤벨 아이콘, 선택된 운동명(`Bench Press (바벨 벤치프레스)`), 현재 세트 번호(`1세트 기록 (Set 1)`), 닫기(X) 버튼.
- **빠른 무게 조절 칩**: `[+2.5]`, `[+5.0]`, `[+10.0]` 원터치 증감 칩.
- **가로 3열 컴팩트 입력 필드**: `무게(kg)`, `횟수`, `RPE` 3열 배치로 키보드 노출 상태에서도 세트 저장 버튼이 한 화면에 완전히 표시됨.
- **동적 Epley 1RM 배지**: 80kg x 10회 입력 시 `🔥 예상 1RM (Epley 공식)  106.7 kg` 연보라색 하이라이트 배지가 실시간 노출.
- **숫자 키패드 IME 동선**: `다음(Next)` 키를 누르면 무게 → 횟수 → RPE로 포커스가 즉시 점프하며, 엔터 시 자동 저장.

#### UX 평가 포인트
- 키보드가 팝업되어도 입력 필드나 저장 버튼이 가려지지 않는 완벽한 시야 확보.
- 1RM 피드백이 주는 즉각적인 동기부여 효과.

### [Screen 04] 유산소 전용 세트 입력 바텀시트
- **파일명**: `04_set_editor_cardio.png`
- **화면 분류**: 입력 바텀시트 (Cardio Set Editor Sheet)

![유산소 세트 입력 바텀시트](../screenshots/04_set_editor_cardio.png)

#### 주요 UI 구성 요소
- **스마트 라벨 전환**: `무게` 대신 **`속도/레벨`**, `횟수` 대신 **`시간(분)`**으로 라벨 및 플레이스홀더 자동 전환.
- **시간 전용 퀵 칩**: `[+5분]`, `[+10분]`, `[+15분]` 칩으로 1터치 시간 입력 지원.
- **불필요한 요소 배제**: 유산소 운동에서는 의미가 없는 1RM 계산 배지를 자동으로 숨겨 화면을 극도로 심플하게 유지.

#### UX 평가 포인트
- 근력 운동과 유산소 운동의 본질적 입력 차이를 매끄럽게 흡수한 스마트 UI 전환.
- 유산소 중 흔들리는 손으로도 쉽게 누를 수 있는 큰 퀵 칩 터치 타겟.

---

### [Screen 05] 종목 및 세트가 기록된 운동 화면
- **파일명**: `05_session_detail_logged.png`
- **화면 분류**: 세션 상세 (Workout Session Detail - With Sets)

![기록 완료된 세션 화면](../screenshots/05_session_detail_logged.png)

#### 주요 UI 구성 요소
- **자동 휴식 타이머 바**: 세트 저장 직후 상단 대시보드 아래에 `⏳ 세트 간 휴식 중 01:28` 카운트다운, `+30초 연장`, `일시정지(❚❚)`, `종료(✕)` 컨트롤 노출.
- **유산소 기록 테이블**: `StairMaster (천국의 계단)` 카드 내 `Set | 속도/레벨 | 시간(분) | RPE` 헤더와 `1 | 8 | 15분 | 8.0` 데이터 행.
- **웨이트 기록 테이블**: `Bench Press (바벨 벤치프레스)` 카드 내 `Set | Weight | Reps | RPE` 헤더와 `1 | 80.0 kg | 10 | -` 데이터 행.
- **종목별 코멘트 작성**: 카드 하단 `[+ 종목 평가 / 피드백 남기기]` 버튼으로 자극 부위, 기구 세팅값 등을 메모 가능.

#### UX 평가 포인트
- 근력과 유산소가 한 화면에 공존할 때 테이블 헤더와 단위가 각각에 맞게 최적화되어 표시되는 일관성.
- 세트 저장 후 사용자가 별도로 타이머 앱을 켤 필요 없이 즉각 활성화되는 휴식 카운트다운.

### [Screen 06] 오늘의 운동 완료 대화상자
- **파일명**: `05_session_finish_dialog.png`
- **화면 분류**: 모달 대화상자 (Workout Completion Dialog)

![운동 완료 대화상자](../screenshots/05_session_finish_dialog.png)

#### 주요 UI 구성 요소
- **축하 아이콘 & 타이틀**: 파티 폭죽 아이콘(`🎉`)과 볼드체 `오늘의 운동 완료!` 헤딩.
- **운동 결과 요약**:
  - `총 운동 시간: 06:31`
  - `완료한 세트: 총 2세트`
  - `오늘도 목표를 달성하셨습니다. 세션을 저장하고 마무리하시겠습니까?`
- **액션 버튼**: 좌측 `운동 계속하기`(취소), 우측 메인 액센트 `세션 완료 및 저장`.

#### UX 평가 포인트
- 실수로 완료 버튼을 눌렀을 때 운동 데이터가 즉시 닫히지 않도록 방어하는 안전장치.
- 운동 종료 시 성취감을 고취하는 따뜻하고 긍정적인 카피라이팅.

### [Screen 07] 단일 활성 세션 충돌 방지 대화상자
- **파일명**: `07_session_conflict_dialog.png`
- **화면 분류**: 인터랙티브 충돌 해결 대화상자 (Active Session Conflict Dialog)

![세션 충돌 방지 대화상자](../screenshots/07_session_conflict_dialog.png)

#### 주요 UI 구성 요소
- **경고/안내 아이콘**: 덤벨 아이콘과 `이미 진행 중인 운동이 있습니다` 타이틀.
- **상세 상황 설명**:
  - *"현재 'Workout Session' 세션이 진행 중입니다. 한 번에 하나의 운동 세션만 진행할 수 있습니다. 기존 운동으로 이동하거나, 기존 운동을 종료하고 새 운동을 시작할 수 있습니다."*
- **3-Way 선택지**:
  1. `진행 중인 운동으로 이동` (가장 추천되는 보라색 주 버튼)
  2. `종료 후 새로 시작` (연보라색 보조 버튼)
  3. `취소` (하단 텍스트 버튼)

#### UX 평가 포인트
- 동시 세션 생성이라는 비현실적 오류를 차단하면서도, 사용자의 이전 데이터를 날리지 않고 3가지 명확한 탈출구를 제공하는 완성도 높은 인터랙션.

### [Screen 08-A] 상단 인앱 활성 배너 & 세션 목록 (진행 중)
- **파일명**: `08_session_list_active.png`
- **화면 분류**: 세션 목록 (Workout Session List - Active Session Highlight)

![세션 목록 진행 중 카드](../screenshots/08_session_list_active.png)

#### 주요 UI 구성 요소
- **최상단 고정 `ActiveWorkoutBanner`**:
  - 스톱워치 아이콘, `운동 진행 중 ⏱ 03:47`, 세션명, `[운동 복귀 >]` 원터치 복귀 버튼.
  - 세션 상세 화면을 벗어나도 전역 네비게이션 상단에 유지되어 즉시 운동으로 복귀 가능.
- **벤토 그리드 세션 카드 (`BentoSessionCard`)**:

  - 우측 더보기 메뉴(`⋮`) 및 상세 진입 화살표(`>`).

#### UX 평가 포인트
- 다른 탭을 둘러보거나 잠시 홈으로 나갔다 와도 내가 지금 운동 중임을 잊지 않게 만드는 엠비언트 UI(Ambient UI).

#### UX 평가 포인트
- 상태 변화에 따른 애니메이션의 매끄러움과 완료 데이터의 명확한 시각화.

- **타이틀 및 안내 문구**: `루틴 라이브러리 (Routines)`, `자주 하는 운동 루틴을 선택하여 즉시 세션을 시작하세요`.
- **루틴 카드**:
  - 루틴명: `Leg Day (하체)`, `Pull Day (등/이두)`.
  - 포함 종목 수: `총 2개 운동 포함`, `총 3개 운동 포함`.
  - 우측 액션: 편집(연필), 더보기 메뉴(`⋮`).
  - 포함 운동 프리뷰 리스트: `Squat (바벨 스쿼트) 🏋️ 프리  80.0kg x 5회`, `Leg Press (레그 프레스) 🏋️ 프리  120.0kg x 10회`.
  - 카드 하단 메인 액션 버튼: **`[▶ 이 루틴으로 세션 시작 (Start)]`**.
- **우측 하단 FAB**: 신규 루틴 생성을 위한 `+` 플로팅 액션 버튼.

#### UX 평가 포인트
- 루틴에 진입하지 않고도 카드 외부에서 포함된 종목과 목표 프리셋을 한눈에 파악할 수 있는 스캐너빌리티(Scannability).
- 버튼 하나로 루틴의 모든 종목이 세션으로 즉시 복제 및 시작되는 원터치 워크플로우.

- **화면 분류**: 시스템 알림 (Foreground Service Chronometer Notification)

![상태바 타이머 알림](../screenshots/12_system_notification_timer.png)

#### 주요 UI 구성 요소
- **Android OS 네이티브 크로노미터 알림 (`WorkoutTimerService`)**:
  - 앱을 닫거나 유튜브, 인스타그램 등 다른 앱을 실행 중이어도 상단 상태바 및 알림 서랍에 초 단위 운동 시간이 계속 흐름.
  - 시스템 크로노미터(`setUsesChronometer(true)`) 기반으로 구현되어 매초 CPU를 깨우지 않아 **배터리 소모율 0%** 달성.

#### UX 평가 포인트
- 플로팅 팝업(PiP)처럼 다른 앱의 화면을 가려 멀티태스킹을 방해하지 않고, OS 상단바에 미니멀하게 녹아드는 정제된 사용성.
